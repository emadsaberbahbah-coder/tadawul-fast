## S2 — Design (WHY on the file header)
The four market pages' **Warnings** cell is non-empty on 100 % of live rows and averages 1,052.5 chars / 24.01 tags on Global_Markets (max 35; 6,150 rows > 20 tags); 9,413,635 chars per export, 9,708 of 9,791 rows > 5 tags. The bytes are engine telemetry (eq_roi_backfill 26,442 tokens, margin_publish 19,621, sheet_margin_unit 19,263, sheet_horizon_label 18,850, acquisition_* 38,217, analyst_trend_block_applied 9,669, rel_path 9,662, f7_settle 9,515, quote_*_from_suffix 8,604 each, fund_cache 8,311). A reader census (file:line in the header WHY) shows that many downstream gates parse Warnings substrings, so this is **gate-token-preserving compaction behind an allow-list**, not truncation.

- **Gate** `TFB_WARNINGS_COMPACT` = `off` (default) | `observe` | `enforce`, explicit words only (`1`/`true`/`on` read as off — the sync's tri-state convention). **off is byte-identical** to v6.64.14 on the sheet payload, the `_Status` stamp, `sync_summary.json` and `_Run_Log`; the only emission is one startup boot line `[WARNINGS-COMPACT v6.65.0] selftest=… requested=off effective=off …` next to the P-162 / P-162b lines (the GitHub-lane equivalent of a /health gate state; the Render /health cannot see workflow env).
- **observe** = countable only: one `[WARNINGS-COMPACT v6.65.0] <page> | mode=observe status=WOULD_COMPACT rows=… removable_rows=… tags=-… chars=-… (-x%) mean=A>B gt5=P>Q top=[…] sink=- selftest=PASS` log line + one `_Run_Log` row (FW-3 10-column shape, Status `WOULD_COMPACT`, Details JSON with run_id/ts_utc) per ranked page per leg, `res._stamp_meta['wc']`, a `warnings_compact` block in `--json-out`. Cells untouched; the seam returns the **same rows object**.
- **enforce** = the full original string of every changed row is written FIRST to the per-leg JSONL sink `sync_row_telemetry_<Page>_<run id>.jsonl` (`TFB_WARNINGS_SINK_DIR`, default `.`; records keyed run_id|symbol with full string, compacted string, removed tokens, counts; atomic tmp+rename; the per-process `_RUN_ID` suffix keeps multi-cycle inline recoveries from overwriting each other). Only then is the compacted COPY returned. A sink failure prints `::warning::`, appends `_Run_Log` `SINK_FAILED` and returns the UNCOMPACTED matrix — telemetry is never destroyed without a copy (fail-closed on the data, fail-open on the write path).
- **Allow-list (MOVABLE):** sheet_horizon_label (except the literal `sheet_horizon_label:invest_period_label:unknown` — see B2 below), analyst_trend_block_applied, rel_path, quote_exchange_from_suffix, quote_currency_from_suffix, fund_cache, intrinsic_soft_ceiling_applied, bearish_reco_high_modeled_upside, fundamentals_lkg, sector_from_eodhd_verified, yahoo_chart_enrichment_applied, fund_coherence_skipped, bar_age_failover_exhausted, intrinsic_rejected_outlier(x0.2|x0.1), market_cap_subunit_*, fctuple_vintage, provider_route, previous_close_incoherent_dropped, percent_change_suspect_dropped, sanitized, revenue_currency_suspect, market_cap_currency_suspect; the `:observe` forms of margin_publish / eq_roi_backfill / f7_settle; `fund_unit_contract:yahoo:*` (1,007 tokens). **Witness rule:** suffix-less margin_publish / eq_roi_backfill and non-observe f7_settle are enforce witnesses and stay; `fund_unit_contract:eodhd:*` (955 tokens) is the points witness `_margin_publish_contract` reads and stays. **Every other head — every reader token and every unknown/future head — stays verbatim.**
- **Severity-first ordering** of the kept tokens (identity_quarantined, operator_quarantine_stub, fetch_failed, price_bar_stale, xprovider_price_conflict, provider_target_*, fund_coherence_quarantined, sheet_quote_conflict, sheet_tuple_*, sheet_margin_unknown, forecast_capped_at_ceiling, f7_settle_failed, rank_skipped_settlement_failure, recommendation_forced_hold_missing_price, low_data_trust, rank_skipped_low_trust, confidence_default_suspected, analyst_lkg), then the rest in original relative order — so the acquisition quadruple and the `sheet_margin_unit` receipts stay LAST, exactly where `present_instrument_row` re-emits them; `dict.fromkeys` dedup; `'; '` join (the `_mark_preserved_acquisitions` convention).
