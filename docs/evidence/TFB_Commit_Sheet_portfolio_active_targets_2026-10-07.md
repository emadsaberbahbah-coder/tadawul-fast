The rebuild now reads one bounded, unformatted active-ledger snapshot. It detects the header below title rows and requires one unambiguous Symbol, Status, quantity, native unit Buy Price/Avg Cost and Ccy/Currency column. Inactive, Closed, Sold and zero-quantity positions are excluded. Aggregate Cost Basis, fees and SAR totals cannot stand in for unit cost. Unreadable, truncated, empty, conflicting, duplicate, noncanonical known registry or mathematically invalid active inputs fail before fetching. Duplicate active lots require an explicit aggregation contract; this change does not invent one.

The snapshot supplies the exact explicit backend request and both acquisition censuses. Foreign, duplicate or currency-mismatched responses cannot publish, even when the general market membership switch is off. Existing persistence may restore an omitted holding, but final injection reapplies the same snapshot's quantity and unit cost after all restoration stages. Every requested active identity must appear exactly once before any clear or write. An omitted new holding with no predecessor fails closed and preserves the prior page. Rebuild remains default OFF; an OFF caller with explicit symbols retains its existing behavior, while an empty-symbol portfolio request is rejected.

Canonical Position Cost is quantity × unit cost; Position Value is quantity × native quote price; Unrealized P/L is their difference; its percentage is in percentage points. Values use the existing engine's six-decimal rounding. Known position cost survives a missing price; price-dependent values become blank. Explicit SAR fields are separate and require positive native/SAR prices establishing conversion. No default FX is invented. Quote currency must agree with ledger currency before publication. Quote values/provenance, manual decisions and notes are preserved. The 122-column schema, provider configuration, budgets, risk/identity/eligibility controls, floors, leases and off/observe/enforce policy modes remain unchanged.
